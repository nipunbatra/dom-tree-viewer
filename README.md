# DOM Tree Viewer

A web-based tool to visualize the DOM structure of any website.

## Features

- Enter any URL and fetch its DOM tree
- Interactive, collapsible tree view
- Toggle attributes and text content
- Statistics panel with element distribution chart
- Pure HTML/CSS/JS - no frameworks required

## Usage

Open `index.html` in a browser, enter a URL, and click "Fetch & Visualize".

## CORS Proxy

Uses [AllOrigins](https://allorigins.win/) API to bypass CORS restrictions.
